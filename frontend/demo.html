Can one fake headline flip the trading agent?

Type a genuine headline and the attacker's fake version. Two identical agents decide on the same market day: the clean twin reads only the genuine news, the attacked agent also reads the fake. If they decide differently, the fake news flipped the decision. Compare the agent without a defense and with the RobustHFT defense layer, which checks the news against what the market's own prices say.

The demo server is not running. This page needs it to run the agent. In the project folder run make demo (or .venv/bin/python scripts/demo_server.py) and open the address it prints.

Numbers are for the attacked agent of the last run. Run an example to fill them in.

    Two simplifications in this demo: every headline gets the same weight (the experiments weight by relevance and recency), and every agent starts with no position and no memory of earlier days. The paper's results come from thousands of such decisions over 100 simulated markets, not from one example.

    🛡
    Runs locally. The demo server listens only on this computer and sends nothing anywhere; the local LLM reader, if you switch it on, also runs on this computer. The examples are about a fictional company, Nordwind Systems. The market is simulated and there is no trading. Not investment advice.
